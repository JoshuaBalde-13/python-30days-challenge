# Python Daily Challenges — Toward Data Analyst / Data Engineer

Daily Python practice, one topic per day, working toward a career in data
(data analyst / data engineer). Inspired by the structure of
[30 Days of Python](https://github.com/asabeneh/30-days-of-python), reworked
to be more challenging and focused on data-relevant problems instead of
generic exercises.

## Roadmap

**Phase 1 — Core Python**
Day 01 — Variables, Data Types, Built-in Functions
Day 02 — Operators
Day 03 — Strings
Day 04 — Lists
Day 05 — Tuples
Day 06 — Sets
Day 07 — Dictionaries
Day 08 — Conditionals
Day 09 — Loops
Day 10 — Functions
Day 11 — Modules
Day 12 — List Comprehensions

**Phase 2 — Data-Relevant Python**
Day 13 — File Handling (CSV/JSON)
Day 14 — Exception Handling
Day 15 — Working with dates/time
Day 16 — Intro to NumPy
Day 17 — Intro to Pandas — Series & DataFrames
Day 18 — Pandas — Cleaning data
Day 19 — Pandas — Grouping & Aggregation
Day 20 — Pandas — Merging/Joining datasets
Day 21+ — Mini data projects, review, and stretch challenges
